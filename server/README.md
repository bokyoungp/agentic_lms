# 강의 도우미 에이전트 서버

가이드(index.html)에 붙는 선택 기능이다. 서버가 없어도 가이드는 그대로 동작한다. 추가 설치 없이 Python 3.9 이상이면 실행된다.

## 실행 (강사 PC)

    cd guide/server
    python bot_server.py

터미널에 수강자 접속 주소, 강사 설정 주소, 관리 토큰이 출력된다.

| 대상 | 주소 | 비고 |
|---|---|---|
| 수강자 | http://강사PC주소:8787/ | 서버가 가이드를 함께 내려 준다. 따로 설정이 없다 |
| 수강자(파일로 연 경우) | 가이드 우하단 AI 도우미 > 설정에 서버 주소 입력 | file:// 로 연 가이드도 서버와 통신한다 |
| 강사 | http://127.0.0.1:8787/admin | 강사 PC에서만 열린다. 관리 토큰 필요 |

## 제공자 바꾸기

- 기본값은 mock이다. 키 없이 규칙 기반으로 에이전트 구조(도구 호출 반복)를 시연한다.
- 강사 설정 화면에서 openai 또는 anthropic을 고르고 적용하면 다음 질문부터 바뀐다. 재시작이 필요 없다.
- 키는 `.env`(`.env.example` 복사) 또는 강사 설정 화면에 입력한다. 화면에 입력한 키는 서버 메모리에만 있고 파일에 저장되지 않는다.
- 모델 이름은 설정 화면에서 바꾼다. 기본값은 임시이므로 사용할 모델로 확인이 필요하다.
- 실패 시 대신 쓸 제공자를 지정하면 장애가 나도 답이 이어진다.
- OpenAI 호환 서버(Ollama 등)는 openai의 주소만 바꾸면 된다. 서버가 `max_tokens`만 받으면 bot_config.json의 `openai_token_param`을 바꾼다.

## 파일 구성과 수업 단계

| 파일 | 역할 | 대응 단계 |
|---|---|---|
| llm.py | 제공자별 호출 형식 변환, 설정, 폴백 | 02, 05 |
| tools.py | 조회 도구 5개, 힌트 공개 규칙 | 03, 07 |
| agent.py | 판단-행동-관찰 반복, 반복 상한, 도움 모드 판정, 최종 검증 | 04, 06, 08 |
| bot_server.py | HTTP, 요청 제한, 로그, 강사 설정 | |
| kb.json | 가이드 내용(증상, 힌트, 확인 기준). 가이드를 고치면 build.py가 다시 만든다 | |

## 수업 시연 순서

1. mock에서 같은 질문을 하고 "에이전트 동작 보기"를 펼친다. 도구가 호출된 순서가 보인다.
2. 강사 설정에서 openai 또는 anthropic으로 바꿔 같은 질문을 한다. 화면은 그대로이고 답만 달라진다.
3. 힌트를 열지 않은 TODO의 정답을 물어본다. 도구가 차단하고 답이 방향 질문으로 바뀐다. 규칙은 프롬프트가 아니라 코드가 지킨다.
4. 질문에 `OPENAI_API_KEY=sk-...` 형태를 붙여 넣는다. 서버에서 값이 지워진 채로 전달된다.

## 운영 시 알아 둘 점

- 질문 로그는 `logs/`에 저장된다(질문 200자, 키 마스킹). 수강자에게 수집 사실을 알리고 수업이 끝나면 지운다. 보관 기준은 기관 정책 확인이 필요하다.
- 분당 5회, 사용자당 60회로 제한한다(bot_config.json의 limits). 단계 02~05 실습과 같은 API 키를 쓰면 한도를 나눠 쓰므로 별도 키를 권장한다.
- 학습자는 브라우저가 만든 ID로 구분한다. 로그인은 없다.
- 힌트 열림 상태는 학습자 화면이 보내는 값이다. 조작하면 우회할 수 있다.
- 서버가 꺼지거나 키가 없으면 도우미는 가이드의 증상 검색 결과로 대체한다.
